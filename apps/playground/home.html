The compiler knows a request can run twice.

Tape is a small language for Cloudflare Workers and Durable Objects, compiled to Wasm. It refuses a set of mistakes that lose or double data when a request is retried, and every request can be replayed and traced, with no tracing code.

What is checked

  • The page runs the real thing. The editor above uses the compiler, the host and the OTLP view the service uses, and SQLite as Wasm. hello.tape is {{wasm}} of Wasm.
  • Every artefact is made, not typed. Each run, refusal, trace and number on this page came out of the real compiler, host and simulator when the page was built, and a test compares them with the command line.
  • Every claim has a check. STATUS.md lists what Tape claims, the check that fails when each claim breaks, how strong that check is, and what is known to be broken.
