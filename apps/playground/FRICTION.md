# Friction log: the playground

Written while building `apps/playground/` on 22 November 2026, on the tree just before the language's 0.1 and then at 0.1.
The page runs the repository's own compiler, host, simulator, formatter and the service's `otlp()` in a browser,
unchanged; what had to be worked around is below. Outside `apps/`, only the host's µs span timing (`host/`) and the
placement of span events in `otlp()` (`service/src/view.ts`) were changed.

| # | What | Where | Resolution |
|---|---|---|---|
| 1 | **node:sqlite binds every JavaScript number as REAL.** `SELECT typeof(?1), ?1 / 2` with 7 gives `'real', 3.5` (checked with `DatabaseSync` directly). The host passes every Tape `Int` parameter as a number (`host/memory.ts`, `readParams`), so under `nodesql.ts` (the CLI, `tape sim`, the tests) an `Int` is REAL inside SQL: integer division and `typeof` differ from what the program means. sql.js binds an int32 as INTEGER, so the page differed from the CLI until it copied the REAL binding. Workers' `ctx.storage.sql` was not checked. | `nodesql.ts`, `host/memory.ts` | the page reproduces node:sqlite (`(?N * 1.0)`, `src/sqlite.ts`), and `test.ts` compares 61 preset requests through both. **Open**: decide what an `Int` parameter should be (bigint binding would make it INTEGER in node:sqlite) |
| 2 | `sim/world.ts`'s `drain` uses `setImmediate`, which only Node has; the simulator throws `setImmediate is not defined` in a browser or a Worker. | `sim/world.ts` | the page's worker defines it (a `MessageChannel`; `setTimeout(0)` is clamped to 4 ms after five nestings). A `queueMicrotask`-free `drain` in sim/ would not need it |

## Not done, or not verified

- **Phones and IME**: the overlay is a native textarea, so IME composition, selection handles and the on-screen
  keyboard are the browser's own; none of that was run on a phone (unverified on device). The 375 px layout was
  checked in Chrome's mobile emulation only.
- **Font metrics**: the overlay was measured on macOS Chrome with SF Mono (`ui-monospace`). Other platforms fall back
  to Menlo, Consolas or Liberation Mono; alignment there is by the same construction (one grid cell, the same font
  settings, nothing in the `<pre>` that changes a glyph's width) but was not measured.
- **The trace SVG and the theme switch**: the SVG is now inlined on both pages (its `<style>` taken out and served as
  `a/trace.*.css`, inside `@layer trace`, so the page's `--tr-*` values win whatever trace.tape's selectors), so the
  theme toggle reaches it. Nothing in it can run: the policy allows no inline script or handler.
